Learn Deep Q-Network (DQN)

Q-learning with a deep convolutional network, made stable by experience replay, a target network and error clipping: the network, the loss and gradient, the full algorithm step by step, target-update timelines and worked numerical targets. Book: Sutton & Barto §16.5 (Mnih et al., 2015).

One-paragraph summary

DQN = Q-learning + a deep convolutional network $Q(s,a;\theta)$ that reads raw pixels. Naïve Q-learning with a network is unstable (correlated samples, a target that moves with every update, off-policy bootstrapping — the deadly triad). DQN stabilises it with three changes: (1) experience replay — train on random minibatches from a large memory; (2) a target network $\theta^-$ — a frozen copy used to compute the target, refreshed every $C$ updates; (3) clipping — rewards to $\{-1,0,+1\}$ and the TD error to $[-1,1]$.

1. From tabular Q-learning to DQN

$$\text{Tabular:}\;\; Q(S,A)\leftarrow Q(S,A)+\alpha\Big[R+\gamma\max_{a'}Q(S',a')-Q(S,A)\Big]$$
Q-learning (recall, Ch 6)(book eq. 6.8)

2. The network and the Atari setup

  • State $\phi(s_t)$: the last 4 frames, each converted to luminance and resized to $84\times84$, stacked into an $84\times84\times4$ tensor. Stacking restores velocity information that a single frame lacks (the game is partially observable from one frame).
  • Actions: 4–18 joystick actions per game (a frame-skip of $k=4$: the chosen action is repeated for 4 frames).
  • Output layer: one value per action. A single forward pass gives all $Q(s,a;\theta)$, so $\max_{a'}$ is cheap.
  • Reward: change in game score, clipped to $\{-1,0,+1\}$; the same hyperparameters are used for every game.
Exam tip

Why does the network output one value per action rather than taking $(s,a)$ as input? One forward pass yields every $Q(s,\cdot)$, so computing $\max_{a'}Q(s',a')$ costs a single pass instead of $|\mathcal A|$ passes.

3. The loss, the target and the gradient

  1. Bellman optimality target. For a sampled transition $(s,a,r,s')$, define $$y=\begin{cases}r&\text{if }s'\text{ is terminal}\\[2pt] r+\gamma\max_{a'}Q(s',a';\theta^-)&\text{otherwise}\end{cases}$$ Note: it uses the target network parameters $\theta^-$, not the online ones.
  2. Squared TD loss on a minibatch sampled uniformly from the replay memory $D$: $$L(\theta)=\mathbb E_{(s,a,r,s')\sim U(D)}\Big[\big(y-Q(s,a;\theta)\big)^2\Big]$$
  3. Gradient — $y$ is treated as a constant (semi-gradient again), only $Q(s,a;\theta)$ is differentiated: $$\nabla_\theta L=\mathbb E\Big[\big(y-Q(s,a;\theta)\big)\,\nabla_\theta Q(s,a;\theta)\Big]\quad(\text{factor }2\text{ absorbed into }\alpha)$$
  4. Update by a stochastic minibatch step (RMSProp in the paper): $\theta\leftarrow\theta+\alpha\,\delta\,\nabla_\theta Q(s,a;\theta)$ with $\delta=y-Q(s,a;\theta)$, averaged over the minibatch.
$$L_i(\theta_i)=\mathbb E_{(s,a,r,s')\sim U(D)}\Big[\big(r+\gamma\max_{a'}Q(s',a';\theta_i^-)-Q(s,a;\theta_i)\big)^2\Big]$$
DQN loss(Mnih et al. 2015, eq. 3)
$$\nabla_{\theta_i}L_i=\mathbb E\Big[\big(r+\gamma\max_{a'}Q(s',a';\theta_i^-)-Q(s,a;\theta_i)\big)\,\nabla_{\theta_i}Q(s,a;\theta_i)\Big]$$
DQN gradient(Mnih et al. 2015, eq. 4)
Common mistakes
  • Forgetting that a terminal next state has no bootstrap: $y=r$ (not $r+\gamma\max Q$).
  • Using $\theta$ instead of $\theta^-$ in the target (that is plain Q-learning, not DQN).
  • Backpropagating through the target. The gradient is only through $Q(s,a;\theta)$.
  • Updating only the output of the taken action $a$: the other actions' outputs receive zero gradient for this sample.

4. Why plain Q-learning with a network is unstable

Source of instabilityWhat goes wrongDQN's answer
Correlated samplesConsecutive frames are almost identical; SGD assumes (roughly) i.i.d. data, so the network over-fits the current region of the game and forgets earlier ones.Experience replay (random minibatches)

5. Fix 1 — experience replay

  1. After each environment step, store the transition $e_t=(\phi_t,a_t,r_t,\phi_{t+1})$ (plus a terminal flag) in a memory $D$ of capacity $N$ (the last $N$ transitions; old ones are overwritten).
  2. Every step, draw a uniform random minibatch (32 transitions) from $D$.
  3. Compute targets and take one gradient step on that minibatch.
BenefitWhy
Breaks temporal correlationRandom minibatches look closer to i.i.d.
Data efficiencyEach transition is used in many updates.
Smooths the data distributionAverages over past behaviour policies — avoids oscillation and feedback loops.
Allowed because Q-learning is off-policyIt can learn from data generated by older policies. (Sarsa could not.)
CostMemory ($N=10^6$ stored transitions); uniform sampling ignores importance (prioritised replay fixes this).

6. Fix 2 — the target network

Keep two copies of the network: the online network $\theta$ (trained every step) and a frozen target network $\theta^-$ used only to compute targets. Every $C$ updates copy $\theta^-\leftarrow\theta$.

The convention “copy every $C$ updates” is what the paper uses; exam questions state it explicitly. The target is therefore always between $0$ and $C$ updates old.

7. Fix 3 — reward and error clipping

  • Reward clipping: all positive rewards $\to+1$, negative $\to-1$, zero stays $0$. Keeps error scales comparable across games so one learning rate works for all, but loses reward magnitude.
  • Error clipping: clip $\delta=y-Q(s,a;\theta)$ to $[-1,+1]$. Equivalent to using the Huber-like loss: quadratic inside $[-1,1]$, linear outside. It limits the size of any one gradient and further improves stability.
$$\delta_{\text{clip}}=\max\!\big(-1,\min(1,\,y-Q(s,a;\theta))\big)$$
Clipped TD error(Mnih et al. 2015)

8. The full algorithm, step by step

Deep Q-learning with experience replay and target networkoff-policybootstrapsmodel-free
Initialise replay memory D to capacity N
Initialise action-value network Q with random weights θ
Initialise target network Q⁻ with weights θ⁻ ← θ
For episode = 1…M:
    Initialise s₁ = {x₁};  φ₁ = φ(s₁)               // 4-frame stack of 84×84 luminance
    For t = 1…T:
        With probability ε pick a random action a_t,
            otherwise a_t = argmaxₐ Q(φ_t, a; θ)       // ε annealed 1.0 → 0.1
        Execute a_t, observe reward r_t and image x_{t+1}
        φ_{t+1} = φ(s_t, a_t, x_{t+1})
        Store (φ_t, a_t, r_t, φ_{t+1}) in D
        Sample a random minibatch of (φ_j, a_j, r_j, φ_{j+1}) from D
        y_j = r_j                                       // if φ_{j+1} is terminal
        y_j = r_j + γ·maxₐ′ Q⁻(φ_{j+1}, a′; θ⁻)         // otherwise
        Gradient step on (y_j − Q(φ_j, a_j; θ))²   w.r.t. θ only     // error clipped to [−1,1]
        Every C steps: θ⁻ ← θ
Off-policy: behaviour is ε-greedy, target is greedy. Replay and the target network are the two pillars of stability.
  1. Preprocess the frame; stack with the last three.
  2. Act ε-greedily with the online network; repeat the action for $k=4$ frames.
  3. Store the transition in $D$.
  4. Sample a random minibatch (32) from $D$ — only once $D$ holds enough (50,000 in the paper).
  5. Targets from the frozen network: $y=r$ if terminal, else $r+\gamma\max_{a'}Q(\phi',a';\theta^-)$.
  6. Loss and gradient: only on the output $Q(\phi,a;\theta)$ of the taken action; clip the error.
  7. Update $\theta$ (RMSProp).
  8. Every $C$ steps copy $\theta^-\leftarrow\theta$.

9. Worked numerical examples

Example A — one target and one update

Problem

A sampled transition has $r=1$, $\gamma=0.99$, and the next state is non-terminal. The target network gives $Q(s',\cdot;\theta^-)=(2.0,\;3.5,\;1.0)$. The online network gives $Q(s,a;\theta)=4.0$ for the taken action. $\alpha=0.01$. Find $y$, $\delta$, and the update direction.

  1. Greedy next value: $\max_{a'}Q(s',a';\theta^-)=3.5$.
  2. Target: $y=1+0.99\cdot3.5=4.465$.
  3. TD error: $\delta=y-Q(s,a;\theta)=4.465-4.0=0.465$ (within $[-1,1]$; no clipping needed).
  4. Update: $\theta\leftarrow\theta+\alpha\cdot0.465\cdot\nabla_\theta Q(s,a;\theta)$ — increase $Q(s,a)$ slightly.
  5. If the next state were terminal: $y=r=1$, $\delta=1-4.0=-3$, clipped to $-1$ ⇒ decrease $Q(s,a)$ with a bounded-size step.

Example B — minibatch loss

Problem

Minibatch of 3: $(r,\text{terminal?},\max Q^-,\,Q)$ = $(0,\text{no},\,5,\,4.5)$, $(1,\text{no},\,2,\,2.0)$, $(-1,\text{yes},\,\text{–},\,0.5)$, with $\gamma=0.9$. Compute the targets, errors and the mean squared loss.

  1. $y_1=0+0.9\cdot5=4.5$, $\delta_1=4.5-4.5=0$.
  2. $y_2=1+0.9\cdot2=2.8$, $\delta_2=2.8-2.0=0.8$.
  3. $y_3=-1$ (terminal: no bootstrap), $\delta_3=-1-0.5=-1.5$ ⇒ clipped to $-1$ for the gradient.
  4. Squared losses: $0,\;0.64,\;2.25$ (unclipped) ⇒ mean $=(0+0.64+2.25)/3\approx0.963$. With error clipping the third term's gradient magnitude is that of $|\delta|=1$.

Example C — what the target network changes

Problem

With $C=1000$ and $\theta_{500}$ the online weights at step 500, which weights give the target at step 500, and what is the lag at that time?

  1. The last copy was at step 0 (or 1000·k with k=0), so the target uses $\theta^-=\theta_0$ — 500 steps old.
  2. At step 1000, $\theta^-\leftarrow\theta_{1000}$. The lag is therefore between $0$ and $C$ steps (average $C/2$).
  3. Smaller $C$: fresher targets but more feedback/instability (limit $C=1$: plain Q-learning). Larger $C$: stable but slow information propagation.

11. DRQN and Double DQN (extensions)

DRQN — Deep Recurrent Q-Network

Replace the first fully-connected layer by an LSTM so the agent keeps a hidden memory $\mathbf h_t$ of past frames. Use it under partial observability (e.g. flickering screens, one frame instead of four). Trains on sequences from replay. Section 16.5.8.

Double DQN (beyond the syllabus)

DQN's $\max$ over noisy estimates is positively biased (maximisation bias, §6.7). Double DQN picks the action with the online network and evaluates it with the target network: $$y=r+\gamma\,Q\big(s',\arg\max_{a'}Q(s',a';\theta);\theta^-\big)$$

Likely exam questions
  • Name the three modifications and say which problem each solves (correlation → replay; moving target → target network; scale → clipping).
  • Compute $y$ and $\delta$ for a given transition (terminal vs non-terminal; clip to $[-1,1]$).
  • Given $C$, say which weights produce the target at step $t$.
  • Why is DQN off-policy, and why is that needed for replay?
  • Why 4 stacked frames? Why one output per action? What does the clipping lose?
  • What is the deadly triad and which parts does DQN contain?
