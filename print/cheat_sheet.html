RL formula cheat sheet · E1 277o · Sutton & Bartoside 1 of 2: bandits → n-step

General

Incremental rule$\textit{New}\leftarrow\textit{Old}+\textit{StepSize}\,[\textit{Target}-\textit{Old}]$ — any running estimate
Step-size conditions$\sum_n\alpha_n=\infty,\quad\sum_n\alpha_n^2\lt\infty$ — 1/n ok; const α tracks
Return$G_t=\sum_{k=0}^\infty\gamma^kR_{t+k+1}=R_{t+1}+\gamma G_{t+1}$ — compute backwards
Unified return$G_t=\sum_{k=t+1}^{T}\gamma^{k-t-1}R_k$ — T=∞ or γ=1

Ch 2 Bandits

Action value$q_*(a)=\E[R_t\mid A_t=a]$ — target of estimation
Sample average$Q_t(a)=\frac{\sum_{i\lt t}R_i\mathbb 1_{A_i=a}}{\sum_{i\lt t}\mathbb 1_{A_i=a}}$ — stationary
Greedy$A_t=\argmax_aQ_t(a)$; ε-greedy picks greedy w.p. $1-\varepsilon+\varepsilon/k$ — greedy arm also gets ε/k
Incremental mean$Q_{n+1}=Q_n+\frac1n[R_n-Q_n]$ — O(1) memory
Constant α$Q_{n+1}=Q_n+\alpha[R_n-Q_n]=(1-\alpha)^nQ_1+\sum_{i=1}^n\alpha(1-\alpha)^{n-i}R_i$ — non-stationary
UCB$A_t=\argmax_a\big[Q_t(a)+c\sqrt{\ln t/N_t(a)}\big]$ — N=0 ⇒ pick first
Soft-max$\pi_t(a)=e^{H_t(a)}/\sum_be^{H_t(b)}$ — from preferences H
Gradient bandit$H_{t+1}(a)=H_t(a)+\alpha(R_t-\bar R_t)(\mathbb 1_{a=A_t}-\pi_t(a))$ — baseline R̄; all arms updated

Ch 3 MDPs

Dynamics$p(s',r\mid s,a)=\Pr\{S_t=s',R_t=r\mid S_{t-1}=s,A_{t-1}=a\}$ — defines the MDP
Derived quantities$p(s'|s,a)=\sum_rp(s',r|s,a)$, $\ r(s,a)=\sum_rr\sum_{s'}p(s',r|s,a)$ — marginalise p
Constant reward$\sum_k\gamma^k=1/(1-\gamma)$ — r/(1−γ)
State value$v_\pi(s)=\E_\pi[G_t\mid S_t=s]$
Action value$q_\pi(s,a)=\E_\pi[G_t\mid S_t=s,A_t=a]$
v ↔ q$v_\pi(s)=\sum_a\pi(a|s)q_\pi(s,a)$; $\ q_\pi(s,a)=\sum_{s',r}p(s',r|s,a)[r+\gamma v_\pi(s')]$ — needs model for q
Bellman for $v_\pi$$v_\pi(s)=\sum_a\pi(a|s)\sum_{s',r}p(s',r|s,a)[r+\gamma v_\pi(s')]$ — linear system
Bellman for $q_\pi$$q_\pi(s,a)=\sum_{s',r}p(s',r|s,a)[r+\gamma\sum_{a'}\pi(a'|s')q_\pi(s',a')]$
Optimal values$v_*(s)=\max_\pi v_\pi(s)$, $\ q_*(s,a)=\max_\pi q_\pi(s,a)=\E[R_{t+1}+\gamma v_*(S_{t+1})\mid s,a]$
Bellman optimality $v_*$$v_*(s)=\max_a\sum_{s',r}p(s',r|s,a)[r+\gamma v_*(s')]$ — max ⇒ non-linear
Bellman optimality $q_*$$q_*(s,a)=\sum_{s',r}p(s',r|s,a)[r+\gamma\max_{a'}q_*(s',a')]$ — basis of Q-learning
Optimal policy$\pi_*(s)=\argmax_aq_*(s,a)$; $\ v_*(s)=\max_aq_*(s,a)$ — greedy on $q_*$: no model

Ch 4 DP

Policy evaluation$v_{k+1}(s)=\sum_a\pi(a|s)\sum_{s',r}p(s',r|s,a)[r+\gamma v_k(s')]$ — sweep until Δ<θ
Deviate once$q_\pi(s,a)=\sum_{s',r}p(s',r|s,a)[r+\gamma v_\pi(s')]$ — test one-step change
Improvement theorem$q_\pi(s,\pi'(s))\ge v_\pi(s)\ \forall s\ \Rightarrow\ v_{\pi'}(s)\ge v_\pi(s)\ \forall s$ — ⇒ π′ ≥ π
Greedy improvement$\pi'(s)=\argmax_a\sum_{s',r}p(s',r|s,a)[r+\gamma v_\pi(s')]$ — needs model
Value iteration$v_{k+1}(s)=\max_a\sum_{s',r}p(s',r|s,a)[r+\gamma v_k(s')]$ — OLD V on right; stop Δ<θ ⇒ err ≤ γθ/(1−γ)

Ch 5 Monte Carlo

Greedy from q$\pi(s)=\argmax_aq(s,a)$ — ES control
IS ratio$\rho_{t:T-1}=\prod_{k=t}^{T-1}\frac{\pi(A_k|S_k)}{b(A_k|S_k)}$ — p cancels; need b>0 where π>0
IS expectation$\E[\rho_{t:T-1}G_t\mid S_t=s]=v_\pi(s)$
Ordinary IS$V(s)=\sum_{t\in\mathcal T(s)}\rho_{t:T(t)-1}G_t\,/\,|\mathcal T(s)|$ — unbiased, high var
Weighted IS$V(s)=\sum_{t\in\mathcal T(s)}\rho_{t:T(t)-1}G_t\,/\,\sum_{t\in\mathcal T(s)}\rho_{t:T(t)-1}$ — biased, low var

Ch 6 TD

Constant-α MC$V(S_t)\leftarrow V(S_t)+\alpha[G_t-V(S_t)]$ — waits for episode end
TD(0)$V(S_t)\leftarrow V(S_t)+\alpha[R_{t+1}+\gamma V(S_{t+1})-V(S_t)]$ — online, bootstrap
TD error$\delta_t=R_{t+1}+\gamma V(S_{t+1})-V(S_t)$
MC error = Σ TD errors$G_t-V(S_t)=\sum_{k=t}^{T-1}\gamma^{k-t}\delta_k$ (V fixed) — if V fixed
Sarsa$Q(S_t,A_t)\leftarrow Q+\alpha[R_{t+1}+\gamma Q(S_{t+1},A_{t+1})-Q(S_t,A_t)]$ — on-policy: A′ taken
Q-learning$Q(S_t,A_t)\leftarrow Q+\alpha[R_{t+1}+\gamma\max_aQ(S_{t+1},a)-Q(S_t,A_t)]$ — off-policy: max
Expected Sarsa$Q(S_t,A_t)\leftarrow Q+\alpha[R_{t+1}+\gamma\sum_a\pi(a|S_{t+1})Q(S_{t+1},a)-Q(S_t,A_t)]$ — lower variance
Double Q-learning$Q_1(S_t,A_t)\leftarrow Q_1+\alpha[R_{t+1}+\gamma Q_2(S_{t+1},\argmax_aQ_1(S_{t+1},a))-Q_1(S_t,A_t)]$ — removes max bias

Ch 7 n-step

n-step return$G_{t:t+n}=R_{t+1}+\gamma R_{t+2}+\dots+\gamma^{n-1}R_{t+n}+\gamma^nV_{t+n-1}(S_{t+n})$ — ends at T ⇒ G_t
n-step TD$V_{t+n}(S_t)=V_{t+n-1}(S_t)+\alpha[G_{t:t+n}-V_{t+n-1}(S_t)]$ — update waits n steps
Error reduction$\max_s|\E_\pi[G_{t:t+n}|S_t=s]-v_\pi(s)|\le\gamma^n\max_s|V_{t+n-1}(s)-v_\pi(s)|$
n-step Sarsa return$G_{t:t+n}=R_{t+1}+\dots+\gamma^{n-1}R_{t+n}+\gamma^nQ_{t+n-1}(S_{t+n},A_{t+n})$
Off-policy n-step TD$V(S_t)\leftarrow V(S_t)+\alpha\rho_{t:t+n-1}[G_{t:t+n}-V(S_t)]$
IS ratio span$\rho_{t:h}=\prod_{k=t}^{\min(h,T-1)}\pi(A_k|S_k)/b(A_k|S_k)$
Off-policy n-step Sarsa$Q(S_t,A_t)\leftarrow Q+\alpha\rho_{t+1:t+n}[G_{t:t+n}-Q(S_t,A_t)]$ — ratio starts t+1

Ch 9 Function approximation

Value error$\overline{\mathrm{VE}}(\mathbf w)=\sum_s\mu(s)[v_\pi(s)-\hat v(s,\mathbf w)]^2$ — weighted by μ
On-policy distribution$\eta(s)=h(s)+\sum_{\bar s}\eta(\bar s)\sum_a\pi(a|\bar s)p(s|\bar s,a)$, $\ \mu(s)=\eta(s)/\sum_{s'}\eta(s')$
SGD$\mathbf w_{t+1}=\mathbf w_t-\tfrac12\alpha\nabla[v_\pi(S_t)-\hat v(S_t,\mathbf w_t)]^2=\mathbf w_t+\alpha[v_\pi(S_t)-\hat v(S_t,\mathbf w_t)]\nabla\hat v(S_t,\mathbf w_t)$ — needs true $v_\pi$
General SGD target$\mathbf w_{t+1}=\mathbf w_t+\alpha[U_t-\hat v(S_t,\mathbf w_t)]\nabla\hat v(S_t,\mathbf w_t)$ — bootstrap ⇒ semi-gradient
Linear$\hat v(s,\mathbf w)=\mathbf w^\top\mathbf x(s)$, $\ \nabla\hat v=\mathbf x(s)$ — ∇v̂ = x
Linear TD(0)$\mathbf w_{t+1}=\mathbf w_t+\alpha(R_{t+1}+\gamma\mathbf w_t^\top\mathbf x_{t+1}-\mathbf w_t^\top\mathbf x_t)\mathbf x_t$ — v̂(terminal)=0
Expected linear TD update$\E[\mathbf w_{t+1}\mid\mathbf w_t]=\mathbf w_t+\alpha(\mathbf b-\mathbf A\mathbf w_t)$ ⇒ fixed point where $\mathbf b=\mathbf A\mathbf w_{TD}$
A and b$\mathbf A=\E[\mathbf x_t(\mathbf x_t-\gamma\mathbf x_{t+1})^\top]$, $\ \mathbf b=\E[R_{t+1}\mathbf x_t]$
TD fixed point$\mathbf w_{TD}=\mathbf A^{-1}\mathbf b$ — not min of VE
Polynomial basis$x_i(s)=\prod_{j=1}^ks_j^{c_{i,j}}$, $\ (n+1)^k$ features — include const feature
Fourier basis$x_i(s)=\cos(\pi\,\mathbf s^\top\mathbf c^i)$; $\ \alpha_i=\alpha/\|\mathbf c^i\|$
Single hidden layer$\hat v(x,\mathbf w)=\sum_{k=1}^{K}w_k\,\sigma\big(\sum_{l=1}^{d}w_{kl}x_l\big)$; $\ K(d+1)$ weights (no bias) — weights, no bias
Activations$\tanh\xi\in(-1,1)$; $\ \sigma(\xi)=\frac1{1+e^{-\xi}}\in(0,1)$, $\sigma'=\sigma(1-\sigma)$; $\ \mathrm{ReLU}=\max(0,\xi)$ — need non-linearity
TD with a network$\mathbf w_{t+1}=\mathbf w_t+\alpha[R_{t+1}+\gamma\hat v(X_{t+1},\mathbf w_t)-\hat v(X_t,\mathbf w_t)]\nabla_{\mathbf w}\hat v(X_t,\mathbf w_t)$
Logistic unit $\hat v=\sigma(\mathbf w^\top\mathbf x)$squared error: $\mathbf w\leftarrow\mathbf w+\alpha[U-\hat v]\hat v(1-\hat v)\mathbf x$; cross-entropy: $\mathbf w\leftarrow\mathbf w+\alpha[U-\hat v]\mathbf x$

Ch 13 Policy gradient

Gradient ascent on $J$$\boldsymbol\theta_{t+1}=\boldsymbol\theta_t+\alpha\,\widehat{\nabla J(\boldsymbol\theta_t)}$, $\ \E[\widehat{\nabla J}]\approx\nabla J$
Soft-max policy$\pi(a|s,\boldsymbol\theta)=\frac{e^{h(s,a,\boldsymbol\theta)}}{\sum_be^{h(s,b,\boldsymbol\theta)}}$, $\ h=\boldsymbol\theta^\top\mathbf x(s,a)$ — discrete actions
Performance (episodic)$J(\boldsymbol\theta)\doteq v_{\pi_{\boldsymbol\theta}}(s_0)$
Policy gradient theorem$\nabla J(\boldsymbol\theta)\propto\sum_s\mu(s)\sum_aq_\pi(s,a)\nabla\pi(a|s,\boldsymbol\theta)$ (no $\nabla\mu$, no $\nabla q$) — no ∇μ
Expectation form$\nabla J\propto\E_\pi\big[\sum_aq_\pi(S_t,a)\nabla\pi(a|S_t,\boldsymbol\theta)\big]=\E_\pi\big[G_t\frac{\nabla\pi(A_t|S_t,\boldsymbol\theta)}{\pi(A_t|S_t,\boldsymbol\theta)}\big]$
Log-derivative trick$\frac{\nabla\pi}{\pi}=\nabla\ln\pi$ (eligibility vector)
REINFORCE$\boldsymbol\theta_{t+1}=\boldsymbol\theta_t+\alpha\,G_t\,\nabla\ln\pi(A_t|S_t,\boldsymbol\theta_t)$; discounted: extra factor $\gamma^t$ — MC: wait for episode end
Soft-max eligibility vector$\nabla\ln\pi(a|s,\boldsymbol\theta)=\mathbf x(s,a)-\sum_b\pi(b|s,\boldsymbol\theta)\mathbf x(s,b)$
Zero-mean score$\E_{A\sim\pi}[\nabla\ln\pi(A|s)]=\sum_a\nabla\pi(a|s)=\nabla1=\mathbf0$ — self-check
Theorem with baseline$\nabla J\propto\sum_s\mu(s)\sum_a\big(q_\pi(s,a)-b(s)\big)\nabla\pi(a|s,\boldsymbol\theta)$, valid since $\sum_ab(s)\nabla\pi=b(s)\nabla1=0$
REINFORCE with baseline$\boldsymbol\theta_{t+1}=\boldsymbol\theta_t+\alpha\big(G_t-b(S_t)\big)\nabla\ln\pi(A_t|S_t,\boldsymbol\theta_t)$; $\ b=\hat v(S_t,\mathbf w)$, $\ \mathbf w\leftarrow\mathbf w+\alpha^{\mathbf w}\delta\nabla\hat v$, $\ \delta=G_t-\hat v$ — b = v̂(s,w)
Linear critic step$\alpha^{\mathbf w}=0.1/\E\big[\|\nabla\hat v(S_t,\mathbf w)\|^2_\mu\big]$
TD error$\delta_t=R_{t+1}+\gamma\hat v(S_{t+1},\mathbf w)-\hat v(S_t,\mathbf w)$ ($\hat v(\text{terminal})\doteq0$) — 0 at terminal
Actor update$\boldsymbol\theta_{t+1}=\boldsymbol\theta_t+\alpha\,I\,\delta_t\,\nabla\ln\pi(A_t|S_t,\boldsymbol\theta_t)$, $\ I\leftarrow\gamma I$ ($I=1$ at episode start) — δ replaces G_t
Critic update$\mathbf w_{t+1}=\mathbf w_t+\beta\,\delta_t\,\nabla\hat v(S_t,\mathbf w_t)$ (semi-gradient TD(0)); linear: $\nabla\hat v=\mathbf x(S_t)$ — β ≫ α
Two time-scales$\alpha_t,\beta_t\gt0$; $\sum\alpha_t=\sum\beta_t=\infty$; $\sum\alpha_t^2,\sum\beta_t^2\lt\infty$; $\ \alpha_t/\beta_t\to0$
Gaussian policy$\pi(a|s,\boldsymbol\theta)=\frac{1}{\sigma\sqrt{2\pi}}\exp\!\big(-\frac{(a-\mu)^2}{2\sigma^2}\big)$
Mean and std parameters$\mu=\boldsymbol\theta_\mu^\top\mathbf x_\mu(s)$, $\ \sigma=\exp(\boldsymbol\theta_\sigma^\top\mathbf x_\sigma(s))$ — σ>0 via exp
Gaussian scores$\nabla_{\boldsymbol\theta_\mu}\ln\pi=\frac{a-\mu}{\sigma^2}\mathbf x_\mu(s)$; $\ \nabla_{\boldsymbol\theta_\sigma}\ln\pi=\big(\frac{(a-\mu)^2}{\sigma^2}-1\big)\mathbf x_\sigma(s)$ — log first, then ∇
Sigmoid (2-action) score$\pi(A_1)=\sigma(\theta)$: $\ \frac{d}{d\theta}\ln\pi(A_1)=1-\sigma(\theta)$, $\ \frac{d}{d\theta}\ln\pi(A_2)=-\sigma(\theta)$
Short corridor$J(p)=-\frac{2(2-p)}{p(1-p)}$, optimum $p^*=2-\sqrt2\approx0.586$, $J\approx-11.66$ — stochastic optimum

§16.5 DQN

Semi-gradient Q-learning$\mathbf w_{t+1}=\mathbf w_t+\alpha\big[R_{t+1}+\gamma\max_a\hat q(S_{t+1},a,\mathbf w_t)-\hat q(S_t,A_t,\mathbf w_t)\big]\nabla\hat q(S_t,A_t,\mathbf w_t)$
Bellman optimality ($Q^*$)$Q^*(s,a)=\E_{s'}\big[r+\gamma\max_{a'}Q^*(s',a')\mid s,a\big]$
DQN target$y=\begin{cases}r&\text{terminal }s'\\ r+\gamma\max_{a'}Q(s',a';\theta^-)&\text{otherwise}\end{cases}$ — y=r at terminal
Loss$L_i(\theta_i)=\E_{(s,a,r,s')\sim U(D)}\big[\big(r+\gamma\max_{a'}Q(s',a';\theta_i^-)-Q(s,a;\theta_i)\big)^2\big]$
Gradient ($\theta^-$ fixed)$\nabla_{\theta_i}L_i=-2\,\E\big[\big(y-Q(s,a;\theta_i)\big)\nabla_{\theta_i}Q(s,a;\theta_i)\big]$ — θ⁻ held fixed
SGD step on one tuple$\theta_{i+1}=\theta_i+\alpha\big[y-Q(s,a;\theta_i)\big]\nabla_{\theta_i}Q(s,a;\theta_i)$, error $y-Q$ clipped to $[-1,1]$ — clip error [−1,1]
Target-network updateevery $C$ updates $\theta^-\leftarrow\theta$: $\ \theta_i^-=\theta_{C\lfloor i/C\rfloor}$ (lag $0..C-1$) — every C steps
Reward clipping$r\in\{+1,0,-1\}$ (score up / unchanged / down)
Uniform replay$\Pr(\text{tuple})=1/T$ for $T$ stored tuples; buffer keeps the last $N$ — breaks correlation
Linear semi-gradient TD(0) — recipe ① $\hat v(s)=\mathbf w^\top\mathbf x(s)$ ② $\delta=r+\gamma\mathbf w^\top\mathbf x(s')-\mathbf w^\top\mathbf x(s)$ (next term 0 if terminal) ③ $\mathbf w\leftarrow\mathbf w+\alpha\delta\,\mathbf x(s)$ ④ in time order, use the updated $\mathbf w$. $d$ = number of columns of the feature matrix $X$ (rows = states); full column rank ⇒ non-redundant features. Tabular = one-hot $X=I$.
Score function ∇ln π take $\ln\pi$ first, differentiate term by term. Check: $\E_{a\sim\pi}[\nabla\ln\pi]=0$ and the gradient has the shape of $\mathbf x$. Gaussian: $\nabla_{\theta_\mu}=\frac{a-\mu}{\sigma^2}\mathbf x_\mu$, $\nabla_{\theta_\sigma}=\big[\frac{(a-\mu)^2}{\sigma^2}-1\big]\mathbf x_\sigma$. Bernoulli: $\nabla\ln\pi(1)=(1-\pi_1)\mathbf x$. Baseline $b(s)$ must not depend on the action.
REINFORCE vs actor–critic REINFORCE: unbiased, high variance, waits for episode end. Actor–critic: $\delta$ replaces $G_t$ — online, lower variance, biased; critic step β ≫ actor step α (critic must track the current policy).
DQN replay ⇒ decorrelated, reused data; frozen $\theta^-$ ⇒ stable target (moving target + bootstrapping + off-policy + deep net = unstable). Terminal tuple: $y=r$, no max term. Larger $C$ ⇒ steadier but staler target.
Exam routine state the update rule first · tabulate $(s,a,r,s',a')$ · keep a running table (cross out, rewrite) · write target → δ → α·δ → new value · say your terminal/γ assumptions · check: probabilities sum to 1, Bellman residual 0.
