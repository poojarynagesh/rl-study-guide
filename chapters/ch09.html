On-policy Prediction with Approximation

The value function is no longer a table but a parameterised function $\hat v(s,\mathbf w)\approx v_\pi(s)$ with $d\ll|\mathcal S|$ weights. Updating one state now generalises to many others — more powerful, but harder to analyse. This chapter covers estimating $v_\pi$ from on-policy data.

Function approximation also makes RL applicable to partially observable problems: if $\hat v$ cannot depend on some aspect of the state, it is as if that aspect is unobservable. (It cannot, however, augment the state with memories of past observations.)

9.1 Value-function approximation

Every prediction method shifts the estimate at some state toward an update target $u$: write $s\mapsto u$.

MethodUpdate $s\mapsto u$
Monte Carlo$S_t\mapsto G_t$
TD(0)$S_t\mapsto R_{t+1}+\gamma\hat v(S_{t+1},\mathbf w_t)$
n-step TD$S_t\mapsto G_{t:t+n}$
DP policy evaluation$s\mapsto\E_\pi[R_{t+1}+\gamma\hat v(S_{t+1},\mathbf w_t)\mid S_t=s]$ (arbitrary $s$)

Each update is a supervised-learning training example (input $s$, desired output $u$) — "function approximation" when outputs are numbers. But not every supervised method suits RL; RL needs methods that:

  • learn online from incrementally acquired data (not repeated passes over a static training set);
  • handle nonstationary targets — the policy changes in GPI, and bootstrapped targets (DP, TD) change even for a fixed policy.

9.2 The prediction objective $\overline{\mathrm{VE}}$

With approximation, making one state more accurate makes others less accurate — so we must say which states we care about, via a distribution $\mu(s)\ge0$, $\sum_s\mu(s)=1$:

$$\overline{\mathrm{VE}}(\mathbf w)\doteq\sum_{s\in\mathcal S}\mu(s)\Big[v_\pi(s)-\hat v(s,\mathbf w)\Big]^2$$
Mean square value error(9.1)

$\sqrt{\overline{\mathrm{VE}}}$ (root VE) is often plotted. Usually μ = fraction of time spent in $s$ — the on-policy distribution (stationary distribution under π for continuing tasks). For episodic tasks, with start distribution $h(s)$ and $\eta(s)$ = expected time steps in $s$ per episode:

$$\eta(s)=h(s)+\sum_{\bar s}\eta(\bar s)\sum_a\pi(a\mid\bar s)p(s\mid\bar s,a),\qquad \mu(s)=\frac{\eta(s)}{\sum_{s'}\eta(s')}$$
On-policy distribution (episodic)(9.2), (9.3)

With discounting, treat $1-\gamma$ as termination by putting a factor γ in the second term of (9.2).

  • Is $\overline{\mathrm{VE}}$ the right objective? Our real goal is a better policy; the best value function for that need not minimise $\overline{\mathrm{VE}}$. But no clearly better alternative exists yet.
  • Global optimum $\mathbf w^*$: possible for linear approximators. Local optimum: typically the best for nonlinear (ANNs, trees). Some methods may diverge ($\overline{\mathrm{VE}}\to\infty$).

9.3 Stochastic-gradient and semi-gradient methods

$\mathbf w=(w_1,\dots,w_d)^\top$; $\hat v(s,\mathbf w)$ differentiable in $\mathbf w$. Suppose each example gives the true value $S_t\mapsto v_\pi(S_t)$, with states drawn from μ. SGD takes a small step down the gradient of that example's squared error:

$$\mathbf w_{t+1}\doteq\mathbf w_t-\tfrac12\alpha\nabla\big[v_\pi(S_t)-\hat v(S_t,\mathbf w_t)\big]^2=\mathbf w_t+\alpha\big[v_\pi(S_t)-\hat v(S_t,\mathbf w_t)\big]\nabla\hat v(S_t,\mathbf w_t)$$
SGD on the squared value error(9.4), (9.5)

$\nabla f(\mathbf w)\doteq\big(\tfrac{\partial f}{\partial w_1},\dots,\tfrac{\partial f}{\partial w_d}\big)^\top$ (9.6). Why only a small step? We don't want zero error on one example — we want a balance of errors across states. Convergence results assume α decreases per (2.7) ⇒ SGD converges to a local optimum.

In practice $v_\pi(S_t)$ is unknown; substitute a target $U_t$:

$$\mathbf w_{t+1}\doteq\mathbf w_t+\alpha\big[U_t-\hat v(S_t,\mathbf w_t)\big]\nabla\hat v(S_t,\mathbf w_t)$$
General SGD for state-value prediction(9.7)

If $U_t$ is unbiased ($\E[U_t|S_t=s]=v_\pi(s)$) — e.g. the MC return $G_t$ — convergence to a local optimum is guaranteed (decreasing α).

Bootstrapping targets ($G_{t:t+n}$, the DP target, $R+\gamma\hat v(S',\mathbf w)$) depend on $\mathbf w_t$, so they're biased and the step (9.4)→(9.5), which assumes the target is independent of $\mathbf w$, is invalid. Bootstrapping methods account for the effect of $\mathbf w$ on the estimate but ignore its effect on the target — they include only part of the gradient: semi-gradient methods.

  • Less robust convergence than true gradient methods (but reliable in the linear case).
  • Usually much faster learning (Ch 6–7), and continual / online — usable for continuing tasks.

9.4 Linear methods

$$\hat v(s,\mathbf w)\doteq\mathbf w^\top\mathbf x(s)\doteq\sum_{i=1}^dw_ix_i(s),\qquad \nabla\hat v(s,\mathbf w)=\mathbf x(s)$$
Linear value function; its gradient is the feature vector(9.8)

$\mathbf x(s)$ is the feature vector; each $x_i:\mathcal S\to\mathbb R$ is a feature (a basis function). The SGD update becomes $\mathbf w_{t+1}\doteq\mathbf w_t+\alpha\big[U_t-\hat v(S_t,\mathbf w_t)\big]\mathbf x(S_t)$.

  • The linear case has one optimum (or one set of equally good optima) ⇒ local = global. Gradient MC converges to the global optimum of $\overline{\mathrm{VE}}$ (decreasing α).
  • Semi-gradient TD(0) also converges, but needs a separate theorem — and to a point near the optimum: the TD fixed point.
  • Exercise 9.1 — tabular methods are linear FA with one-hot features: $x_i(s)=1$ if $i=s$, else 0.

The TD fixed point

$$\mathbf w_{t+1}\doteq\mathbf w_t+\alpha\big(R_{t+1}+\gamma\mathbf w_t^\top\mathbf x_{t+1}-\mathbf w_t^\top\mathbf x_t\big)\mathbf x_t = \mathbf w_t+\alpha\Big(R_{t+1}\mathbf x_t-\mathbf x_t(\mathbf x_t-\gamma\mathbf x_{t+1})^\top\mathbf w_t\Big)$$
Linear semi-gradient TD(0)(9.9)
$$\E[\mathbf w_{t+1}\mid\mathbf w_t]=\mathbf w_t+\alpha(\mathbf b-\mathbf A\mathbf w_t),\qquad \mathbf b\doteq\E[R_{t+1}\mathbf x_t]\in\mathbb R^d,\quad \mathbf A\doteq\E\big[\mathbf x_t(\mathbf x_t-\gamma\mathbf x_{t+1})^\top\big]\in\mathbb R^{d\times d}$$
Expected update(9.10), (9.11)
$$\mathbf b-\mathbf A\mathbf w_{TD}=\mathbf 0\;\Rightarrow\;\mathbf w_{TD}\doteq\mathbf A^{-1}\mathbf b$$
TD fixed point — where linear semi-gradient TD(0) converges(9.12)
Why it converges: A is positive definite (proof sketch)

Write $\E[\mathbf w_{t+1}|\mathbf w_t]=(\mathbf I-\alpha\mathbf A)\mathbf w_t+\alpha\mathbf b$ (9.13): only $\mathbf A$ matters for stability. If $\mathbf A$ is positive definite ($\mathbf y^\top\mathbf A\mathbf y>0$ for $\mathbf y\ne0$), $\mathbf w$ is shrunk toward the fixed point for small α, and $\mathbf A^{-1}$ exists. For continuing tasks, $\mathbf A=\mathbf X^\top\mathbf D(\mathbf I-\gamma\mathbf P)\mathbf X$ (D = diag(μ), P = transition matrix under π, X = feature matrix). The key matrix $\mathbf D(\mathbf I-\gamma\mathbf P)$ has positive diagonal, negative off-diagonal; row sums are positive (P stochastic, γ < 1) and column sums are $\mathbf 1^\top\mathbf D(\mathbf I-\gamma\mathbf P)=\boldsymbol\mu^\top-\gamma\boldsymbol\mu^\top\mathbf P=(1-\gamma)\boldsymbol\mu^\top>0$ because μ is stationary ($\boldsymbol\mu=\mathbf P^\top\boldsymbol\mu$). Hence positive definite ⇒ on-policy TD(0) is stable. This crucially uses the on-policy distribution; with other update distributions bootstrapping + FA can diverge (Ch 11).

$$\overline{\mathrm{VE}}(\mathbf w_{TD})\le\frac{1}{1-\gamma}\min_{\mathbf w}\overline{\mathrm{VE}}(\mathbf w)$$
Error bound at the TD fixed point (continuing case)(9.14)
TD vs MC with function approximation

TD's asymptotic error can be up to $\frac{1}{1-\gamma}$ times the best possible (which MC attains) — large when γ ≈ 1. But TD has much lower variance and learns faster. Which wins depends on the problem, the approximation, and how long learning continues. Analogous bounds hold for linear semi-gradient DP and (next chapter) semi-gradient Sarsa(0); for n-step methods the bound tightens as n grows, approaching 0 as n → ∞.

9.5 Feature construction for linear methods

Features are how we add prior domain knowledge: they should correspond to aspects of the state along which generalisation is appropriate. Limitation of linear forms: no interactions between features (e.g. pole balancing: high angular velocity is good or bad depending on the angle) unless we add features for combinations.

9.5.1 Polynomials

$$x_i(s)=\prod_{j=1}^{k}s_j^{\,c_{i,j}},\qquad c_{i,j}\in\{0,1,\dots,n\}\;\Rightarrow\;(n+1)^k\text{ features}$$
Order-n polynomial basis for k state dimensions(9.17)

E.g. $\mathbf x(s)=(1,s_1,s_2,s_1s_2)^\top$: the constant allows affine functions, the product captures interaction. Ex 9.2: each of the $k$ exponents independently takes $n+1$ values ⇒ $(n+1)^k$. Ex 9.3: $(1,s_1,s_2,s_1s_2,s_1^2,s_2^2,s_1s_2^2,s_1^2s_2,s_1^2s_2^2)$ is $n=2$, $k=2$ with $\mathbf c_i$ ranging over all of $\{0,1,2\}^2$. Exponential growth in $k$ ⇒ select subsets. Not recommended for online learning.

9.5.2 Fourier basis

$$x_i(s)=\cos(i\pi s),\ s\in[0,1],\ i=0,\dots,n \qquad\qquad x_i(\mathbf s)=\cos\big(\pi\,\mathbf s^\top\mathbf c^i\big),\ c^i_j\in\{0,\dots,n\}$$
Fourier cosine basis (1-D and k-D, order n)(9.18)
  • Set the period τ to twice the interval and use only cosines (even functions) — "half-even" functions are easier than "half-odd" ones (often discontinuous at the origin).
  • $\mathbf c^i$ entries set the frequency along each dimension; a 0 means constant along that dimension; both non-zero ⇒ an interaction, with direction given by their ratio.
  • Per-feature step sizes (Konidaris et al.): $\alpha_i=\alpha/\sqrt{(c^i_1)^2+\dots+(c^i_k)^2}$ (or α if all zero).
  • Good performance vs polynomials and RBFs; trouble with discontinuities ("ringing"). Features are global (non-zero almost everywhere) ⇒ hard to represent local properties. Exponential in $k$, but for $k\le5$ you can use all order-n features.
Try it: Figures 9.5 and 9.10 — feature choice on the 1000-state walk (gradient MC)

9.5.3 Coarse coding

Features = overlapping receptive fields (e.g. circles); a binary feature is 1 ("present") if the state is inside. Training at one state changes the weights of all circles containing it, so the value changes over the union of those circles, more where more circles are shared (Fig 9.6).

  • Receptive-field size → breadth of generalisation (narrow / broad); shape → direction (e.g. elongated ⇒ asymmetric generalisation) (Fig 9.7).
  • Acuity — the finest discrimination possible — is controlled more by the total number of features than by their size.
Try it: Example 9.3 / Figure 9.8 — coarseness of coarse coding

Learning a 1-D square wave with interval features (≈50 per unit length), α = 0.2/m where m is the number of features present. Width matters a lot early, very little at the end.

9.5.4 Tile coding

Coarse coding for multi-dimensional continuous spaces, flexible and computationally efficient — "may be the most practical feature representation for modern sequential digital computers". Receptive fields are grouped into partitions (tilings) of tiles. One tiling = state aggregation; several offset tilings give true coarse coding (Fig 9.9: 4 tilings of 4×4 ⇒ 64 features, exactly 4 active).

  • Tile shape controls generalisation: square ⇒ equal in all dimensions; stripes ⇒ along one dimension (ignoring others in that tiling); log stripes ⇒ finer resolution where needed; diagonal stripes ⇒ along a diagonal. Mix horizontal, vertical and conjunctive tilings to get both generalisation and the ability to learn specific conjunctions.
  • Hashing: pseudo-randomly collapse a huge tiling into a much smaller set of (non-contiguous) tiles — memory matches the real demands of the task, not exponential in dimensions.
  • Exercise 9.4 — if one dimension matters more, use tilings whose tiles are narrow across the important dimension and long along the unimportant one (stripes), so the value changes finely with the important variable and generalises broadly over the other.

9.6 Selecting step-size parameters manually

  • Theory (2.7) gives sufficient conditions but too-slow learning; $\alpha_t=1/t$ is not appropriate for TD, nonstationary problems, or function approximation. RLS/LSTD-style optimal matrix step sizes cost $O(d^2)$.
  • Tabular intuition: α = 1 eliminates the error after one target; $\alpha=1/\tau$ approaches the mean of targets after about τ experiences (recent ones weighted most).
$$\alpha\doteq\big(\tau\,\E[\mathbf x^\top\mathbf x]\big)^{-1}$$
Rule of thumb: learn in about τ experiences with substantially the same feature vector(9.19)

Works best when feature vectors have similar length (ideally $\mathbf x^\top\mathbf x$ constant — as in tile coding, where it equals the number of tilings).

9.7 Nonlinear function approximation: artificial neural networks

  • Feedforward ANN (no loops) vs recurrent. Units compute a weighted sum then an activation function — sigmoid $1/(1+e^{-x})$, rectifier $\max(0,x)$, or step (threshold unit).
  • Universal approximation: one hidden layer with enough sigmoid units approximates any continuous function on a compact region (Cybenko 1989). Nonlinearity is essential — linear units stack to a linear function.
  • Deep architectures learn hierarchical abstractions — automatic feature construction instead of hand-crafted features.
  • Trained by SGD with backpropagation (forward pass for activations, backward pass for partial derivatives). In RL, ANNs can learn value functions from TD errors, or maximise reward (gradient bandit, policy gradient).
  • Deep nets are hard to train: overfitting (many weights) and vanishing/exploding gradients. Remedies: cross-validation/early stopping, regularisation, weight sharing, dropout, unsupervised layer-wise pre-training (deep belief networks), batch normalisation, deep residual learning (skip connections).
  • Deep convolutional networks: alternating convolutional (feature maps with shared weights over local receptive fields) and subsampling layers (spatial invariance) — trainable by backprop without special tricks; behind many impressive RL applications (Ch 16).
Exercises 9.7 and 9.8 — a single logistic unit

$\hat v(s,\mathbf w)=\sigma(\mathbf w^\top\mathbf x)$ with $\sigma(z)=1/(1+e^{-z})$, so $\nabla\hat v=\hat v(1-\hat v)\mathbf x$. Squared error (9.7): $\mathbf w\leftarrow\mathbf w+\alpha[U_t-\hat v]\,\hat v(1-\hat v)\,\mathbf x$. Cross-entropy loss $-[U\ln\hat v+(1-U)\ln(1-\hat v)]$ has gradient $-(U-\hat v)\mathbf x$, giving $\mathbf w\leftarrow\mathbf w+\alpha[U_t-\hat v]\,\mathbf x$ — simpler (the $\hat v(1-\hat v)$ factor, which vanishes when the unit saturates, cancels).

9.9–9.10 Memory-based and kernel-based function approximation

  • Memory-based (nonparametric, "lazy learning"): store examples $s'\mapsto g$; answer queries by retrieving relevant examples. Nearest neighbour, weighted average, locally weighted regression (fit a local surface, then discard it).
  • Advantages: not limited to a fixed functional form (accuracy improves with data); focus on states actually visited along trajectories; immediate effect of experience; memory linear in the number of examples, not exponential in dimensions. Challenge: fast queries — k-d trees, parallel hardware, forgetting entries.
  • Kernel $k(s,s')$: strength of generalisation from $s'$ to $s$. Kernel regression:
$$\hat v(s,\mathcal D)=\sum_{s'\in\mathcal D}k(s,s')\,g(s') \qquad\qquad k(s,s')=\mathbf x(s)^\top\mathbf x(s')$$
Kernel regression; any linear method is kernel regression with the inner-product kernel(9.23), (9.24)

The kernel trick: construct kernels directly (no explicit features); many have compact forms that avoid computing in the high-dimensional feature space. Tile coding implicitly generalises according to a kernel (Fig 9.11). An RBF kernel differs from RBF features by being memory-based (centred on stored states) and nonparametric.

9.11 Interest and emphasis

Treating all states equally (the on-policy distribution) gives the strongest theory, but we may care more about some states (e.g. early states in discounted episodes). Interest $I_t\ge0$: how much we care about accurately valuing $S_t$ (any causal choice); it reweights μ. Emphasis $M_t\ge0$ multiplies the update:

$$\mathbf w_{t+n}\doteq\mathbf w_{t+n-1}+\alpha M_t\big[G_{t:t+n}-\hat v(S_t,\mathbf w_{t+n-1})\big]\nabla\hat v(S_t,\mathbf w_{t+n-1}),\qquad M_t=I_t+\gamma^nM_{t-n},\ M_{t\lt0}\doteq0$$

9.12 Summary

  • Generalisation via supervised function approximation: treat each update as a training example. Parameterised FA with $\mathbf w$; rank approximations with $\overline{\mathrm{VE}}$ under μ.
  • n-step semi-gradient TD covers gradient MC (n = ∞) and semi-gradient TD(0) (n = 1). Semi-gradient methods aren't true gradient methods, but linear ones converge, to within a bound of the optimum that tightens as n grows. Some bootstrapping (finite n) usually learns fastest.
  • Features: polynomials generalise poorly online; prefer Fourier or coarse coding — tile coding is especially efficient and flexible; RBFs for smooth 1–2-D tasks. LSTD is most data-efficient but $O(d^2)$. ANNs: deep RL.

Self-test

Why must we specify μ in the objective once we use function approximation?

With fewer weights than states we can't get every state right; improving some states worsens others, so we must say how much we care about each — μ.

Why is gradient MC a true SGD method but semi-gradient TD(0) is not?

MC's target $G_t$ doesn't depend on $\mathbf w$ and is unbiased, so the update is a stochastic gradient of the squared error. TD's target $R+\gamma\hat v(S',\mathbf w)$ depends on $\mathbf w$, but the update ignores that dependence — it uses only part of the gradient.

What is the gradient of a linear value function, and what is the linear SGD update?

$\nabla\hat v(s,\mathbf w)=\mathbf x(s)$; $\mathbf w\leftarrow\mathbf w+\alpha[U_t-\mathbf w^\top\mathbf x(S_t)]\mathbf x(S_t)$.

Define the TD fixed point, and bound its error.

$\mathbf w_{TD}=\mathbf A^{-1}\mathbf b$ with $\mathbf A=\E[\mathbf x_t(\mathbf x_t-\gamma\mathbf x_{t+1})^\top]$, $\mathbf b=\E[R_{t+1}\mathbf x_t]$. $\overline{\mathrm{VE}}(\mathbf w_{TD})\le\frac1{1-\gamma}\min_\mathbf w\overline{\mathrm{VE}}(\mathbf w)$.

Why is it crucial that updates follow the on-policy distribution?

The positive-definiteness of $\mathbf A$ (hence stability of linear TD) relies on μ being the stationary distribution of π. With other distributions, bootstrapping + function approximation can diverge.

In state aggregation on the 1000-state walk, why is the leftmost group's value higher than the average of its true values?

μ is very asymmetric inside that group: states near 100 are visited >3× as often as state 1, so the $\overline{\mathrm{VE}}$-optimal value is pulled toward $v_\pi(100)$, which is higher.

In tile coding with 8 tilings, what α gives exact one-trial learning?

$\alpha=1/8$ (= $1/n$), because exactly 8 binary features are active, so $\mathbf x^\top\mathbf x=8$.

What determines generalisation and what determines acuity in coarse coding?

Size and shape of receptive fields determine (initial) generalisation; the total number (density) of features determines acuity — the finest discrimination possible.

Why prefer asymmetric tile offsets?

Uniform (1,1)-type offsets create diagonal artifacts and uneven generalisation; asymmetric offsets (first odd integers) give homogeneous, well-centred generalisation.

Give two pros and two cons of LSTD.

Pros: most data-efficient linear TD; no step size. Cons: $O(d^2)$ memory and computation; never forgets (bad when the policy changes); needs ε tuning.

What is the "kernel trick"?

Since a linear method equals kernel regression with $k(s,s')=\mathbf x(s)^\top\mathbf x(s')$, you can design kernels directly — often computable compactly — and effectively work in a huge feature space using only stored examples.

In Example 9.4, why does emphatic 2-step TD get $w_2=2$?

The only emphasised update is for state 1, whose 2-step target is $1+1+\hat v(\text{state }3)$. For that to be correct (4), state 3's value $w_2$ must be 2 — the emphasis $M_t=I_t+\gamma^nM_{t-n}$ ensures state 3 (two steps later) is also updated, so it is learned exactly.
