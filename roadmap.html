How to use this guide

A suggested study path, what the coloured boxes mean, and the book's notation — so every formula on later pages reads at a glance.

Suggested study path

  1. Read a chapter page top-to-bottom. Each follows the book's section order and ends with a summary and self-test.
  2. Run the interactive demo on that page and change the hyperparameters. Predict the effect first, then check.
  3. Answer the self-test questions before revealing. Use "Reveal all" only for a final skim.
  4. Click "Mark chapter as studied" — the sidebar shows a green dot and the home page tracks progress (stored only in this browser).
  5. For revision, use the Algorithm catalogue (comparisons), Hyperparameters page, and Formula sheet. They are printable (Ctrl+P; answers print expanded).
  6. Use the search box (top right) to jump to any algorithm, formula or section.

Backup diagrams

The book draws updates as backup diagrams: open circles are states, solid dots are actions, squares are terminal states, and an arc across branches means max. Information flows up from the leaves to the root being updated.

Notation (book pp. xix–xxii, Ch 1–9 subset)

Capital letters are random variables; lower case are their values and scalar functions. Bold lower case are vectors; bold capitals are matrices.
