Learn Function Approximation

From a table of values to a parameterised function: why we need it, the objective, the semi-gradient update derived step by step, linear features and the TD fixed point, neural networks, and a fully worked numerical update. Book: Sutton & Barto Ch 9 (and §10.1 for control).

One-paragraph summary

Tabular methods store one number per state. That is impossible when states are huge (Backgammon $\approx10^{20}$) or continuous (a robot's joint angles) or never seen twice (Atari pixels). So we replace the table by a function $\hat v(s,\mathbf w)\approx v_\pi(s)$ with a small weight vector $\mathbf w\in\mathbb R^d$, $d\ll|\mathcal S|$. We tune $\mathbf w$ by gradient descent on a prediction error. For TD targets the gradient ignores how the target depends on $\mathbf w$ — hence semi-gradient. Changing one weight changes the value of many states: that is generalisation, and also the source of new instabilities.

1. Why a table is not enough

The price of generalisation

With a table, every estimate is independent. With $\hat v(s,\mathbf w)$ you can make the value of one state exactly right only by making others slightly worse. So we must decide which states matter most — that is the role of the state distribution $\mu(s)$ in the objective below.

2. What we minimise: the value-error objective

Let $\mu(s)\ge0$, $\sum_s\mu(s)=1$, be the fraction of time spent in state $s$ when following $\pi$ (the on-policy distribution). The mean-squared value error is

$$\overline{\mathrm{VE}}(\mathbf w)\;=\;\sum_{s\in\mathcal S}\mu(s)\,\Big[v_\pi(s)-\hat v(s,\mathbf w)\Big]^2$$
Mean-squared value error(book eq. 9.1)
  • It is a weighted squared error: frequently visited states count more because we have only $d$ weights to spend.
  • $\mu(s)$ is not the same as the stationary behaviour of the optimal policy; for on-policy methods it is the distribution generated by $\pi$.
  • Goal: find $\mathbf w^*=\arg\min_{\mathbf w}\overline{\mathrm{VE}}(\mathbf w)$. For non-linear $\hat v$ we may only reach a local optimum.
Exam tip

If a question gives a state distribution (e.g. “state $A$ is visited 3× as often as $B$”), the weighted error is $\mu(A)(\cdot)^2+\mu(B)(\cdot)^2$ with $\mu(A)=0.75$, $\mu(B)=0.25$. Always normalise.

3. Gradient descent → semi-gradient (step-by-step derivation)

  1. Per-sample loss. We see one example $S_t\mapsto v_\pi(S_t)$. The squared error on it is $\tfrac12\big[v_\pi(S_t)-\hat v(S_t,\mathbf w_t)\big]^2$.
  2. Move against the gradient with step size $\alpha$: $$\mathbf w_{t+1}=\mathbf w_t-\tfrac12\alpha\nabla_{\mathbf w}\big[v_\pi(S_t)-\hat v(S_t,\mathbf w_t)\big]^2$$
  3. Differentiate (chain rule; $v_\pi$ does not depend on $\mathbf w$): $$\mathbf w_{t+1}=\mathbf w_t+\alpha\big[v_\pi(S_t)-\hat v(S_t,\mathbf w_t)\big]\nabla_{\mathbf w}\hat v(S_t,\mathbf w_t)$$
  4. We do not know $v_\pi$, so we substitute a target $U_t$ (a sample-based estimate of it): $$\mathbf w_{t+1}=\mathbf w_t+\alpha\big[U_t-\hat v(S_t,\mathbf w_t)\big]\nabla_{\mathbf w}\hat v(S_t,\mathbf w_t)$$
  5. Pick the target. The choice decides whether this is a true gradient method.
$$\mathbf w\leftarrow\mathbf w+\alpha\,\big[U_t-\hat v(S_t,\mathbf w)\big]\;\nabla_{\mathbf w}\hat v(S_t,\mathbf w)$$
General SGD update for prediction(book eq. 9.7)

Common mistake

Differentiating the whole squared error $[R+\gamma\hat v(S',\mathbf w)-\hat v(S,\mathbf w)]^2$ gives the residual-gradient method, which has an extra term $-\gamma\nabla\hat v(S',\mathbf w)$. Semi-gradient TD omits it: it is simpler, usually faster, converges in the linear on-policy case — but it is not gradient descent on any objective.

Semi-gradient TD(0) for estimating v̂ ≈ v_πon-policybootstraps
Input: policy π, differentiable v̂(s,w) with v̂(terminal,·)=0
Parameters: step size α > 0
Initialise w ∈ ℝᵈ arbitrarily (e.g. 0)
Loop for each episode:
    Initialise S
    Loop for each step of episode:
        Choose A ~ π(·|S)
        Take A, observe R, S′
        δ ← R + γ·v̂(S′,w) − v̂(S,w)         // TD error (target not differentiated)
        w ← w + α·δ·∇v̂(S,w)                  // ∇v̂ = x(S) in the linear case
        S ← S′
    until S is terminal
Online, incremental, no waiting for the end of the episode (unlike gradient MC).

4. Linear function approximation and the TD fixed point

$$\hat v(s,\mathbf w)=\mathbf w^{\!\top}\mathbf x(s)=\sum_{i=1}^{d}w_i\,x_i(s),\qquad \nabla_{\mathbf w}\hat v(s,\mathbf w)=\mathbf x(s)$$
Linear value function(book eq. 9.8)

The update becomes beautifully simple — a TD-error times feature-vector step:

$$\mathbf w_{t+1}=\mathbf w_t+\alpha\,\delta_t\,\mathbf x_t,\qquad \delta_t=R_{t+1}+\gamma\,\mathbf w_t^{\!\top}\mathbf x_{t+1}-\mathbf w_t^{\!\top}\mathbf x_t$$
Semi-gradient TD(0), linear(book eq. 9.9)

Linear $\overline{\mathrm{VE}}$ is a convex quadratic bowl, so gradient MC finds the global minimum. For TD(0) we ask where the weights settle: in expectation

$$\mathbb E[\Delta\mathbf w]=\alpha\,(\mathbf b-\mathbf A\mathbf w),\quad \mathbf b=\mathbb E[R_{t+1}\mathbf x_t]\in\mathbb R^d,\quad \mathbf A=\mathbb E\!\big[\mathbf x_t(\mathbf x_t-\gamma\mathbf x_{t+1})^{\!\top}\big]\in\mathbb R^{d\times d}$$$$\Longrightarrow\quad \mathbf w_{TD}=\mathbf A^{-1}\mathbf b\quad\text{(the TD fixed point)}$$
TD fixed point(book eqs. 9.10–9.12)
$$\overline{\mathrm{VE}}(\mathbf w_{TD})\;\le\;\frac{1}{1-\gamma}\;\min_{\mathbf w}\overline{\mathrm{VE}}(\mathbf w)$$
Error bound at the TD fixed point(book eq. 9.14)
Why does it still converge?

In the on-policy case the matrix $\mathbf A$ is positive definite (the bootstrapping target is “pulled” by the same distribution it is sampled from). Convergence is lost if the data come from a different distribution (off-policy) — the first corner of the deadly triad below.

With linear methods all the representational power sits in the features. Standard families:

Exam tip — number of weights and step size

Tile coding with $m$ tilings of $t$ tiles per dimension in $k$ dimensions has $m\,t^{\,k}$ weights, exactly $m$ of which are active. A step size “$\alpha=\frac{1}{10m}$” means the value at the visited state moves about 1/10 of the way to the target. (Book §9.5.4; the “1/10” rule is the heuristic $\alpha=(\tau\,\mathbb E[\mathbf x^\top\mathbf x])^{-1}$ with $\tau=10$.)

6. Neural networks as approximators

When good features cannot be designed by hand, let the network learn them. The weights $\mathbf w$ are all layer weights; $\hat v(s,\mathbf w)$ is the output. The same update applies — the only change is that $\nabla_{\mathbf w}\hat v$ is computed by backpropagation.

Caveats
  • $\overline{\mathrm{VE}}$ is no longer convex ⇒ only a local optimum; TD(0) with a nonlinear $\hat v$ has no convergence guarantee.
  • Consecutive RL samples are strongly correlated (violating i.i.d. SGD); this motivates experience replay.
  • Targets change as the network changes; this motivates the target network.

7. From prediction to control

For control we approximate action values $\hat q(s,a,\mathbf w)\approx q_\pi(s,a)$ and use the same recipe with a TD target on the next action:

$$\mathbf w_{t+1}=\mathbf w_t+\alpha\Big[R_{t+1}+\gamma\,\hat q(S_{t+1},A_{t+1},\mathbf w_t)-\hat q(S_t,A_t,\mathbf w_t)\Big]\nabla_{\mathbf w}\hat q(S_t,A_t,\mathbf w_t)$$
Episodic semi-gradient Sarsa(book eq. 10.1/10.2)

Acting is then ε-greedy with respect to $\hat q$: $A=\arg\max_a\hat q(S,a,\mathbf w)$ w.p. $1-\varepsilon$. Replacing $\hat q(S',A')$ by $\max_{a'}\hat q(S',a',\mathbf w)$ gives semi-gradient Q-learning, the ancestor of DQN.

The deadly triad

Instability and divergence can arise when all three are present together:

  1. Function approximation (generalisation couples states),
  2. Bootstrapping (target built from the current estimate),
  3. Off-policy training (data not from the target policy's distribution).

Remove one and you are safe (e.g. gradient MC has no bootstrapping; on-policy semi-gradient TD with linear features is safe). Q-learning with a neural network has all three — which is why DQN needs replay and a target network.

8. Worked numerical example (the kind asked in exams)

Problem

Linear TD(0), $d=2$. Current weights $\mathbf w=(0.5,\;1.0)^\top$. Features $\mathbf x(S)=(1,\;2)^\top$, $\mathbf x(S')=(2,\;0)^\top$. Reward $R=1$, $\gamma=0.9$, $\alpha=0.1$. Perform one semi-gradient TD(0) update.

  1. Prediction at $S$: $\hat v(S)=\mathbf w^\top\mathbf x(S)=0.5\cdot1+1.0\cdot2=2.5$.
  2. Prediction at $S'$: $\hat v(S')=0.5\cdot2+1.0\cdot0=1.0$.
  3. TD error: $\delta=R+\gamma\hat v(S')-\hat v(S)=1+0.9(1.0)-2.5=-0.6$.
  4. Gradient: $\nabla\hat v(S)=\mathbf x(S)=(1,2)^\top$.
  5. Update: $\mathbf w\leftarrow\mathbf w+\alpha\,\delta\,\mathbf x(S)=(0.5,1.0)+0.1(-0.6)(1,2)=(0.5-0.06,\;1.0-0.12)=\mathbf{(0.44,\;0.88)}$.
  6. Check: new $\hat v(S)=0.44+1.76=2.20$ — moved from 2.5 toward the target $1.9$ (not all the way: $\alpha$ is small). Note $\hat v(S')$ also changed, to $0.88$ — that is generalisation (and why the target is “moving”).
Variant — the residual-gradient update (for contrast)

Differentiating the whole error also differentiates the target: $\mathbf w\leftarrow\mathbf w+\alpha\,\delta\,\big(\mathbf x(S)-\gamma\mathbf x(S')\big)$. Here $\mathbf x(S)-\gamma\mathbf x(S')=(1-1.8,\;2-0)=(-0.8,\;2)$, so $\mathbf w=(0.5,1.0)+0.1(-0.6)(-0.8,2)=(0.548,\;0.88)$. Exams normally ask only for the semi-gradient answer $(0.44,0.88)$ above.

State-aggregation mini-example

1000 states, 10 groups of 100, so $d=10$ and $\mathbf x(s)=\mathbf e_{\lceil s/100\rceil}$. A gradient-MC step at $S_t=250$ (group 3) with return $G_t=0.4$ and $\hat v=0.1$: $\Delta w_3=\alpha(0.4-0.1)=0.3\alpha$. All 100 states of group 3 move together. No other weight changes.

9. Traps and exam checklist

Question you may getShort answer
Why “semi”-gradient?The TD target depends on $\mathbf w$ but the gradient treats it as a constant; so it is not the true gradient of any objective.
Which target gives true gradient descent?Monte Carlo return $G_t$ (independent of $\mathbf w$).
What is $\nabla\hat v$ for linear FA?$\mathbf x(s)$ — the feature vector. For tabular it is a one-hot, recovering the usual TD update.
Does semi-gradient TD converge?Linear + on-policy: yes, to $\mathbf w_{TD}=\mathbf A^{-1}\mathbf b$. Off-policy or nonlinear: may diverge.
Weighting in $\overline{\mathrm{VE}}$?On-policy distribution $\mu(s)$; ensures effort is spent on states actually visited.
Tabular as a special case?One-hot features: $\mathbf w$ holds one value per state; $\alpha\delta\mathbf x$ updates only the visited state.
Deadly triad?Function approximation + bootstrapping + off-policy.
What to carry to the next pages

The recipe “weight ← weight + step × error × gradient” is reused everywhere: in policy gradient the “error” becomes a return or TD error multiplying $\nabla\ln\pi$; in DQN it is the Q-learning error multiplying $\nabla Q$ for a deep network.
