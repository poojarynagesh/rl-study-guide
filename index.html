The big picture: how the methods relate

Almost every method in Chapters 4–7 updates a value estimate toward a target. Methods differ along two dimensions (book §8.13, Figure 8.11):

  • Width — does the update use a single sampled next step, or the expected value over all possible next steps (which needs a model)?
  • Depth — does the target bootstrap from the current estimate after one step, or wait for the actual return at the end of the episode?
The one update rule behind (almost) everything $$\text{NewEstimate} \leftarrow \text{OldEstimate} + \text{StepSize}\,\big[\text{Target} - \text{OldEstimate}\big]$$

Bandits (Ch 2): target $=R$. Monte Carlo (Ch 5): target $=G_t$. TD(0) (Ch 6): target $=R_{t+1}+\gamma V(S_{t+1})$. n-step TD (Ch 7): target $=G_{t:t+n}$. Function approximation (Ch 9): the same targets, but the "estimate" is $\hat v(S_t,\mathbf{w})$ and the step is taken along $\nabla \hat v$.
